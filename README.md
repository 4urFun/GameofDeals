# Game of Deals — الإصدار الخامس (أونلاين)

لعبة بطاقات جماعية بالعربية، تشتغل من المتصفح على الجوال والكمبيوتر بدون تحميل تطبيق.

## طريقة النشر على GitHub Pages
1. ارفع كل الملفات (ومجلد `img`) إلى مستودع جديد.
2. من **Settings ← Pages** اختر `Deploy from a branch`، والفرع `main`، والمجلد `/ (root)`، ثم **Save**.
3. بعد دقيقة يصير الموقع على: `https://اسمك.github.io/اسم-المستودع/`

## طريقة اللعب أونلاين
- المضيف يفتح الموقع ← «إنشاء غرفة» ← يرسل الرمز لأصحابه.
- الباقين يفتحون نفس الرابط ← «الانضمام إلى غرفة» ← يكتبون الرمز.
- **المباراة تشتغل من جهاز المضيف**، فلازم يخلي الصفحة مفتوحة طول اللعب. إذا حدّث الصفحة ترجع الغرفة ويرجع اللاعبين تلقائياً.

## التقنية
- الاتصال بين اللاعبين مباشر (WebRTC) عبر مكتبة PeerJS وخادم الربط المجاني الخاص بها، فما يحتاج سيرفر ولا قاعدة بيانات.
- جهاز المضيف يحفظ الحالة الكاملة ويتحقق من كل حركة، ويرسل لكل لاعب **بطاقاته هو فقط**؛ بطاقات الآخرين وكومة السحب ما توصل لجهازه.
- `engine.js` محرك القواعد، و`sim.js` اختبار آلي (`node sim.js`) يلعب 300 مباراة ويتأكد ما تضيع أو تتكرر بطاقة.
- الإعدادات في لوحة التحكم تنحفظ على الجهاز نفسه وتنطبق على الغرف اللي ينشئها.
