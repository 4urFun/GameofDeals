# Game of Deals — الإصدار الخامس (أونلاين)

لعبة البطاقات السعودية Game of Deals للعب مع أصحابك من المتصفح، على الجوال أو الكمبيوتر، بدون تحميل تطبيق.

- اللعب كضيف بدون تسجيل، أو بحساب (اسم مستخدم وكلمة مرور) يحفظ سجلك ونتائجك.
- كل لاعب يشوف بطاقاته هو فقط.
- 265 بطاقة بالتصاميم الأصلية، وكل قواعد الإصدار الخامس.

---

## 1) رفع الموقع على GitHub Pages (مطلوب)

1. سجّل دخولك في github.com واضغط **New repository**. اختر اسماً مثل `game-of-deals`، وخلّه **Public**، ثم **Create repository**.
2. في صفحة المستودع اضغط **Add file ← Upload files**.
3. اسحب **كل محتوى المجلد** (الملفات والمجلدات `css` و`js` و`img` و`supabase` و`tests`) إلى الصفحة، ثم **Commit changes**.
   - لازم يكون `index.html` في أول المستودع مباشرة، مو داخل مجلد.
4. ادخل **Settings ← Pages**. في **Source** اختر `Deploy from a branch`، وفي **Branch** اختر `main` و `/ (root)`، ثم **Save**.
5. بعد دقيقة أو دقيقتين يظهر الرابط فوق الصفحة: `https://اسمك.github.io/game-of-deals/`

الموقع الآن يشتغل باللعب كضيف. إذا تبي الحسابات، كمّل الخطوة 2.

## 2) تفعيل الحسابات وسجل اللعب (اختياري، مجاني)

الحسابات تحتاج قاعدة بيانات، ونستخدم **Supabase** (فيه خطة مجانية).

1. ادخل supabase.com وسجّل، ثم **New project**. اكتب اسماً وكلمة مرور لقاعدة البيانات واختر أقرب منطقة، ثم **Create**.
2. افتح **SQL Editor ← New query**، والصق محتوى الملف `supabase/schema.sql` كاملاً، واضغط **Run**. لازم تطلع رسالة `Success`.
3. افتح **Authentication ← Sign In / Providers ← Email**:
   - خلّ **Enable Email provider** مفعّل.
   - **عطّل Confirm email** (مهم: اللعبة ما تستخدم بريد حقيقي).
   - احفظ.
4. افتح **Project Settings ← API** (أو **Data API / API Keys**) وانسخ:
   - **Project URL**
   - المفتاح العام **anon / publishable**. لا تستخدم مفتاح `service_role` أو `secret` أبداً.
5. في GitHub افتح الملف `js/config.js`، واضغط ✏️، والصق القيمتين:
   ```js
   supabaseUrl: 'https://xxxx.supabase.co',
   supabaseAnonKey: 'eyJ...'
   ```
   ثم **Commit changes**. بعد دقيقة تظهر أزرار «تسجيل الدخول» و«حساب جديد».

المفتاح العام مصمّم ليكون داخل الموقع ومكشوفاً، والحماية تجي من قواعد الأمان في `schema.sql`.

## 3) طريقة اللعب أونلاين

- المضيف: «إنشاء غرفة» ← يرسل الرمز (5 خانات) لأصحابه ← «ابدأ المباراة».
- الباقين: يفتحون نفس الرابط ← «الانضمام إلى غرفة» ← يكتبون الرمز.
- **المباراة تشتغل من جهاز المضيف**، فلازم يخلي الصفحة مفتوحة لين تخلص.
  - إذا حدّث المضيف الصفحة، ترجع الغرفة ويرجع اللاعبين تلقائياً.
  - إذا انقطع نت لاعب، يعيد الاتصال بنفسه.
- إذا ما قدر أحد يتصل (بعض شبكات المدارس والشركات تمنع الاتصال المباشر)، يجرب بيانات الجوال.

## 4) الخصوصية

- **اسم المستخدم ما ينحفظ على الخادم.** الموقع يحوّله إلى بصمة مشفّرة (SHA-256) غير قابلة للعكس، فصاحب الموقع ما يشوف في Supabase إلا رموز عشوائية.
- **كلمة المرور** يشفّرها Supabase، وما يقدر أحد يشوفها، ولا حتى صاحب الموقع.
- **ما نطلب بريد ولا جوال** ولا أي معلومة شخصية.
- **السجل** فيه فقط: تاريخ المباراة، فوز أو خسارة، عدد اللاعبين، المجموعات، المدة. ما فيه أسماء الخصوم.
- كل لاعب يقرأ سجله هو فقط (Row Level Security).
- زر **«حذف الحساب»** يحذف الحساب وكل سجله نهائياً.
- أثناء اللعب، جهاز المضيف يرسل لكل لاعب بطاقاته هو فقط. بطاقات الآخرين وكومة السحب والمهام السرية ما توصل لجهازه أصلاً.
- لأنه ما فيه بريد، **ما يمديك تسترجع كلمة المرور إذا نسيتها**. احفظها.

## 5) ملفات المشروع

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة |
| `css/style.css` | التصميم |
| `js/config.js` | إعدادات Supabase (الملف الوحيد اللي تعدّله) |
| `js/engine.js` | محرك القواعد: البطاقات، الأدوار، الردود، الفوز |
| `js/accounts.js` | الحسابات والسجل |
| `js/ui.js` | الواجهة والاتصال بين اللاعبين |
| `img/` | صور البطاقات (169 نوعاً) والخلفية |
| `supabase/schema.sql` | جداول قاعدة البيانات وقواعد الأمان |
| `tests/sim.js` | اختبار آلي: `node tests/sim.js` يلعب 300 مباراة ويتأكد ما تضيع أو تتكرر بطاقة |

**إعدادات متقدمة:** افتح `رابط-الموقع/#admin` لتعديل أسماء البطاقات وأعدادها وقواعد اللعب (عدد الحركات، المهلة، مجموعات الفوز...). التعديل ينحفظ على جهازك وينطبق على الغرف اللي تنشئها أنت.

## 6) التقنية
- بدون سيرفر خاص: GitHub Pages يستضيف الصفحات، والاتصال بين اللاعبين مباشر (WebRTC) عبر مكتبة PeerJS وخادم الربط المجاني الخاص بها.
- جهاز المضيف يتحقق من كل حركة حسب القواعد، فما يقدر لاعب يغش من جهازه.
