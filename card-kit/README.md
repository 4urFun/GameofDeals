# حزمة تصميم البطاقات (Card Kit) — Game of Deals

هذا المجلد هو **المرجع الرسمي لتصميم البطاقات**. الملفات منسوخة كما هي بدون أي تعديل على التصميم.

| الملف | وظيفته |
|---|---|
| `cards.css` | مقاس البطاقة (260×364)، الخط Tajawal، الألوان، الحواف، توزيع المساحات |
| `card-art.js` | رسومات SVG لكل بطاقة |
| `card-renderer.js` | الدالة `GOD.card(c)` اللي تبني البطاقة من بياناتها |
| `cards-data.js` / `cards-data.json` | بيانات البطاقات: 161 نوع = **265 بطاقة** |
| `cards-index.csv` | فهرس البطاقات للمراجعة في Excel |
| `colors.json` | أسماء الألوان المعتمدة وأكوادها |
| `index.html` | صفحة معاينة تعرض كل البطاقات |
| `card-map.js` | ربط كل بطاقة في محرك اللعبة ببطاقتها في الحزمة (169 → 161) |
| `fonts.css` + `fonts/` | خط Tajawal محلياً (Medium 500 و ExtraBold 800) بدون الحاجة لإنترنت |

## قواعد مهمة
- **محطة وقود: 7 بطاقات، والمجموعة تكتمل بـ 4.**
- أسماء الألوان: سماوي، كحلي، أخضر، أصفر، برتقالي، أحمر، بنفسجي، أسود، رمادي، بني. المحطات `#ca8a04` والمطاعم `#c2410c`.
- لا تعدّل `cards.css` أو `card-art.js` أو `card-renderer.js` إلا إذا كنت تقصد تغيير التصميم نفسه.
- تعديل اسم أو وصف أو عدد بطاقة يكون في `cards-data.js` و`cards-data.json` و`cards-index.csv` معاً.

## المعاينة
بعد الرفع على GitHub Pages افتح: `https://<اسمك>.github.io/<المستودع>/card-kit/`

## الخط
الخط Tajawal موجود داخل `fonts/` ويُحمَّل عبر `fonts.css`، فما يعتمد على Google Fonts.

## الحالة
**الحزمة مربوطة باللعبة.** الملف `js/kit.js` يقرأ `cards.css` و`card-art.js` و`card-renderer.js` و`cards-data.js` و`card-map.js`، ويرسم كل بطاقة داخل عنصر معزول (Shadow DOM) عشان ما يأثر تنسيق الموقع على تصميم البطاقة ولا العكس.
